# Clase 2 · Python y pandas: cargar, mirar, seleccionar y filtrar

La primera clase con código. Se aprende a cargar un CSV con pandas, mirar qué trae, seleccionar
columnas y filtrar filas.

## Qué hay aquí

| Archivo | Para qué |
|---------|----------|
| `slides.html` | Diapositivas de la clase. Doble clic, se abren en el navegador |
| `demo.ipynb` | El demo guiado. Trae el código ya escrito |
| `reto.md` | La consigna del reto: qué se pide y con qué criterios se revisa |
| `reto.ipynb` | El cuaderno donde se resuelve el reto |

## Datos

| Archivo | Dónde se usa |
|---------|--------------|
| [`../datos/estados_financieros.csv`](../datos/estados_financieros.csv) | Demo |
| [`../datos/vehiculos_accidentes.csv`](../datos/vehiculos_accidentes.csv) | Reto |

Los datos viven en `datos/` en la raíz del repositorio, no en esta carpeta. Los cuadernos ya los
leen con la ruta `../datos/...`; funciona sola si no mueve las carpetas.

## Cómo se usa

- **El demo se recorre en clase.** El código ya está escrito: se ejecuta celda por celda, se lee lo
  que sale y se responden las preguntas de interpretación. Aquí no hay que inventar código.
- **El reto se hace después**, solo, con el profesor circulando por el salón. Aquí sí se escribe.
  Es lo que se entrega.
- Trabaje sobre una copia (`demo_mio.ipynb`, `reto_mio.ipynb`) para que `git pull` no le reclame.

## Antes de empezar

- El entorno montado y el `.venv` activo. Todo el procedimiento está en
  [`../INSTALACION.md`](../INSTALACION.md).
- El demo recorrido antes de abrir el reto.
