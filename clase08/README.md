# Clase 8 · Data storytelling

Un análisis no termina en el gráfico: termina en una historia que alguien pueda seguir y usar para
decidir. Cómo pasar de las cifras a cuatro slides encadenadas, con títulos que son mensajes y no
etiquetas.

## Qué hay aquí

| Archivo | Para qué |
|---------|----------|
| `slides.html` | Diapositivas de la clase |
| `demo.ipynb` | El demo guiado. Trae el código ya escrito |
| `reto.md` | La consigna del reto: qué se pide y con qué criterios se revisa |
| `reto.ipynb` | El cuaderno donde se resuelve el reto |

## Datos

| Archivo | Dónde se usa |
|---------|--------------|
| [`../datos/EJECUCION_PRESUPUESTAL.csv`](../datos/EJECUCION_PRESUPUESTAL.csv) | Demo |

**El reto va sobre el dataset de su equipo**, el mismo que viene usando desde el Momento 1. No hay
CSV asignado: el cuaderno arranca apuntando a un archivo de ejemplo y el primer paso es cambiar esa
ruta por la suya.

## Cómo se usa

- **El demo se recorre en clase.** El código ya está escrito: se ejecuta, se lee y se discute qué
  cifra sostiene cada afirmación.
- **El reto se hace después**, solo, con el profesor circulando. Se calculan las cifras propias y se
  redactan los cuatro títulos. Es lo que se entrega.
- Trabaje sobre una copia para que `git pull` no le reclame.

## Antes de empezar

- El entorno activo ([`../INSTALACION.md`](../INSTALACION.md)).
- El demo recorrido antes de abrir el reto.
- El dataset del equipo a la mano, y limpio: una cifra calculada sobre datos sucios se cae en la
  primera pregunta.
