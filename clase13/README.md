Qué es un modelo predictivo y en qué se diferencia de lo que se venía haciendo: separar train y

## Cómo se usa

- **El demo se recorre en clase.** El código ya está escrito: se ejecuta, se lee la métrica que sale
  y se discute si el modelo sirve.
- **El reto se hace después**, solo, con el profesor circulando. Aquí sí se escribe. Es lo que se
  entrega.
- Trabaje sobre una copia para que `git pull` no le reclame.

## Antes de empezar

- El entorno activo, con `scikit-learn` instalado ([`../INSTALACION.md`](../INSTALACION.md)).
- El demo recorrido antes de abrir el reto.
- Lo de las clases 5 y 12: describir una variable y leer un resultado sin sobreinterpretarlo.
