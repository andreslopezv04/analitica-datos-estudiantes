## Cómo se usa

- **El demo se recorre en clase.** El código ya está escrito: se ejecuta, se lee el resultado y se
  discute qué se puede concluir de él.
- **El reto se hace después**, solo, con el profesor circulando. Se escribe el código y se escribe la
  conclusión en español. Es lo que se entrega.
- Trabaje sobre una copia para que `git pull` no le reclame.
