# Clase 4 · Limpieza de datos

Los cinco problemas que trae cualquier dataset real (tipos, faltantes, duplicados, valores
centinela, categorías inconsistentes) y un workflow de cinco pasos para resolverlos. Se limpia, y
además se justifica por escrito cada decisión.

## Qué hay aquí

| Archivo | Para qué |
|---------|----------|
| `slides.html` | Diapositivas de la clase |
| `demo.ipynb` | El demo guiado. Trae el código ya escrito |
| `reto.md` | La consigna del reto: qué se pide y con qué criterios se revisa |
| `reto.ipynb` | El cuaderno donde se resuelve el reto |

## Datos

| Archivo | Dónde se usa |
|---------|--------------|
| [`../datos/educacion_estadisticas.csv`](../datos/educacion_estadisticas.csv) | Demo |
| [`../datos/indicadores_salud.csv`](../datos/indicadores_salud.csv) | Reto |

Otro dataset, otras columnas, los mismos cinco problemas: el workflow se copia, la lista de columnas
no.

## Cómo se usa

- **El demo se recorre en clase.** El código ya está escrito: se ejecuta, se lee lo que sale y se
  responden las preguntas de interpretación.
- **El reto se hace después**, solo, con el profesor circulando. Aquí sí se escribe código, y también
  se escriben las justificaciones. Es lo que se entrega.
- Trabaje sobre una copia para que `git pull` no le reclame.
