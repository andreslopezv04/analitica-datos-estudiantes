# Clase 7 · Principios de visualización

Qué hace que un gráfico se entienda: elegir la forma correcta según la pregunta, quitar todo lo que
no aporta, y dejar figuras listas para publicar en lugar de gráficos por defecto.

## Qué hay aquí

| Archivo | Para qué |
|---------|----------|
| `slides.html` | Diapositivas de la clase |
| `demo.ipynb` | El demo guiado. Trae el código ya escrito |
| `reto.md` | La consigna del reto: qué se pide y con qué criterios se revisa |
| `reto.ipynb` | El cuaderno donde se resuelve el reto |

## Datos

| Archivo | Dónde se usa |
|---------|--------------|
| [`../datos/EJECUCION_PRESUPUESTAL.csv`](../datos/EJECUCION_PRESUPUESTAL.csv) | Demo y reto |

## Cómo se usa

- **El demo se recorre en clase.** El código ya está escrito: se ejecuta, se lee el gráfico que sale
  y se discute por qué esa forma y no otra.
- **El reto se hace después**, solo, con el profesor circulando. Se escriben las figuras y se
  exportan. Es lo que se entrega.
- Trabaje sobre una copia para que `git pull` no le reclame.

## Antes de empezar

- El entorno activo ([`../INSTALACION.md`](../INSTALACION.md)).
- El demo recorrido antes de abrir el reto.
- Lo de la clase 5: saber qué dice la variable antes de dibujarla.
